Rol de HTML, CSS y JavaScript.
------------------------------

- El HTML permitirá la disposición de los elementos del sitio web.
Para crear diferentes pantallas para los servicios que ofrece rueda libre (bicicletas.html, recorridos.html, contacto.html, nosotros.html, etc.)

- EL CSS se usará para cambiar la apariencia del sitio, sobre todo colores y fuentes, para representar la identidad del emprendimiento. También para definir el tamaño de los elementos y sus posiciones.
Fuente: Roboto, Colores: primario, Secundario, Acento, Fondo, Texto.

- El JavaScript tiene la función de crear comportamientos e interacciones de la página que puede afectar el DOM. 
Para cambiar el orden de las tablas de los precios del adquiler de bicicletas y los recorridos al tocar los títulos de las columnas.

Conflictos de selectores
----------------------------------------
#menu a y .activo no estaban funcionando porque no hay ningún elemento en el html que tenga referenciado el id y clase declarados.
A pesar de que #menu tiene seguido un "a", este segundo no se aplica porque es necesario que estos links estén contenidos por un padre que tenga el id menu.
Tal cuál como expresa su especificidad (1,0,1) = (id,-,elemento)
.activo solo requiere que cualquier elemento defina como valor "activo" del atributo class, ya que su especificidad es solo clases (0,1,0)

Layout en dos dimensiones
-------------------------------------------

+----------------------+--------+------------------------------------------------------------+
| Sección              | Layout | Justificación                                              |
+----------------------+--------+------------------------------------------------------------+
| Portada              | grid   | Permite definir de forma más exacta la proporción de los   |
|                      |        | elementos y es más fácil de configurar que en flex.        |
+----------------------+--------+------------------------------------------------------------+
| Galería (rutas)      | flex   | Permite centrar la última fila cuando las tarjetas no      |
|                      |        | caben todas en una misma línea (con grid no hubiera sido   |
|                      |        | tan simple)                                                |
+----------------------+--------+------------------------------------------------------------+
| Fila del formulario  | grid   | Igual que la portada: permite definir con más precisión    |
|                      |        | el tamaño de las columnas.                                 |
+----------------------+--------+------------------------------------------------------------+
| Encabezado           | flex   | Solo requiere alinear elementos horizontalmente y es más   |
|                      |        | sencillo ubicarlos en los extremos, que era lo pedido.     |
+----------------------+--------+------------------------------------------------------------+
| Pie de página        | flex   | Podrían funcionar ambos, pero elegí flex porque en este    |
|                      |        | caso no era necesario que los elementos tuvieran el        |
|                      |        | mismo ancho.                                               |
+----------------------+--------+------------------------------------------------------------+

Utilidades
----------------------------------

> rounded:
 Para redondear las esquinas de los elementos como imágenes y contenedores. También su redondez puede
aplicarse con el número de escalas predefinidas.

> img-fluid:
Hace que una imagen sea responsive, aplica un max-width del 100% con height auto.

> h1-h6:
Equivalente a fs-{n}, para aplicar tamaños y aspectos de títulos en cualquier etiqueta de texto.

> bg-warning:
 Aplica un fondo de color para elementos tipo alerta o destacados. Su color puede cambiarse desde css
modificando las variables --bs-warning y --bs-warning-rgb.

> text-decoration-none: 
Le quita los adornos a los textos como por ejemplo el subrayado en los a links.
